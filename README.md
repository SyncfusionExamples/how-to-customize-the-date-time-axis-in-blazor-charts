# How to Customize the Date-Time Axis in Blazor Charts

## Overview

This sample demonstrates how to configure a Syncfusion [Blazor Chart](https://www.syncfusion.com/blazor-components/blazor-charts) with a DateTime-based x-axis and apply common date-axis customization techniques. The implementation focuses on displaying date values on the horizontal axis, formatting axis labels, configuring custom ranges, and defining interval settings for improved readability. The sample also demonstrates date-time category axis scenarios, helping developers present time-series data more effectively in Blazor applications. It serves as a practical reference for configuring and customizing chart axes when working with date-driven datasets.

## Key Features

- Configures a DateTime-based x-axis in the Syncfusion Blazor Chart component.
- Demonstrates date-time axis rendering for time-series data visualization.
- Shows how to customize axis label formatting to improve readability.
- Applies custom axis range settings using minimum and maximum date values.
- Demonstrates interval customization for date-based axis display.
- Illustrates date-time category axis behavior and configuration.
- Includes code examples for modifying axis presentation and scaling options.
- Provides a working Blazor hosted application structure for chart customization scenarios.

## Prerequisites

- Visual Studio 2022 or Visual Studio Code
- .NET SDK compatible with the project's target framework

## How to Run the Project

**Visual Studio 2022**

1. Clone or download this repository.
2. Open the solution file:

   `CustomDateTimeAxis.sln`

3. Restore all NuGet packages.
4. Build the solution.
5. Run the application using **Ctrl+F5**.

**Visual Studio Code**

1. Open the repository folder in Visual Studio Code.
2. Open the integrated terminal.
3. Navigate to the project directory.

```bash
dotnet restore
dotnet run
```

4. Open the local application URL displayed in the terminal output.

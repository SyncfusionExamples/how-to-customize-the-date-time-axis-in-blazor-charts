# How to Customize the Date-Time Axis in Blazor Charts

This project demonstrates how to configure and customize a DateTime axis in Blazor Charts using built-in configuration options. It focuses on common visualization scenarios where time-based data needs to be displayed clearly and accurately. The sample application shows how to format axis labels, adjust logarithmic base values, and define custom ranges and intervals for the X-axis when working with date and time values.

The example is designed to help developers understand how Blazor Charts handle date-time data and how different configuration settings affect chart rendering and readability. It serves as a practical reference for implementing time-based charts in real-world Blazor applications.

## Project Overview

The project uses Blazor Charts to visualize date-time data along the horizontal axis. It highlights how axis customization can improve data interpretation, especially when dealing with varying time intervals, ranges, or formatting requirements. Developers can explore how different axis settings influence chart behavior and presentation.

## Features

- DateTime axis configuration for Blazor Charts  
- Custom formatting of axis labels  
- Ability to define custom range and interval values  
- Support for adjusting logarithmic base values  
- Practical, working example aligned with official documentation  

## Prerequisites

Before running the project, ensure the following are installed:

- Visual Studio 2022  
- .NET SDK compatible with Blazor projects  

## How to Run the Project

1. Clone or download this repository to your local machine.
2. Open the solution file using Visual Studio 2022.
3. Restore the required NuGet packages by rebuilding the solution.
4. Run the project to launch the sample application.

## Usage

Once the application is running, review the chart configuration code to understand how the DateTime axis is defined and customized. Modify the axis properties to see how changes in intervals, ranges, or label formats affect the chart output. This helps in learning how to tailor charts to specific time-based data requirements.
